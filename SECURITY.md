# Security Policy

**Peace Governance Crisis Room** is a fictional, defensive simulation and training prototype.

## Report Privately

Use GitHub private vulnerability reporting or a private security advisory for:

- Sensitive information accidentally committed to the repository
- Content that could create an unsafe operational or attribution capability
- Credentials, private keys, tokens, or personal data
- Materially misleading security or crisis-governance behavior
- Release-integrity or supply-chain concerns
- A defect that may expose a user's local system when running the Godot project

Do not place sensitive vulnerability details, real target information, credentials, classified information, or harmful procedures in a public issue.

Public issues may be used for non-sensitive documentation defects, fictional scenario quality, accessibility, usability, and clearly public source corrections.

## Scope

This policy covers repository content, source validators, Godot project files, release metadata, and future packaged builds published by this repository.

It does not cover third-party systems, Godot itself, operating systems, or real-world organizations referenced only for general educational context.

## Safety Boundary

This repository does not authorize intelligence collection, surveillance, attribution, crisis communication, automated decision-making, or deployment in a real incident.

A successful source check is not proof that the Godot application runs correctly, that a packaged build is safe, or that a scenario supports a real-world decision. Human authorization, runtime testing, and independent judgment remain required.
