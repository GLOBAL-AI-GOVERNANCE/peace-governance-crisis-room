# Release Notes - v0.3.0-rc1

## Peace OS: Crisis Room - Integrated Web Review Candidate

This candidate establishes **Peace OS: Crisis Room** as the active product identity and targets `GLOBAL-AI-GOVERNANCE/peace-os-crisis-room`.

> Peace OS is the product name. This project is not a computer operating system.

Future desktop-build placeholders use the canonical `Peace_OS_Crisis_Room` filename form. No Windows executable is included in this prerelease.

### Included

- Semantic, local-only browser client for two fictional scenarios.
- Practice, Assessment, and Facilitator modes.
- Complete review before scoring and explicit commit-before-feedback behavior.
- Chance-corrected evidence marking and bounded action capacity.
- Separate confidence, corroboration, authenticity, and public-language decisions.
- Digest-bound human confirmation with invalidation after material changes.
- Structured After-Action Review with copy, download, print, resume, and deletion controls.
- Graceful storage, clipboard, download, and corrupted-session failure handling.
- Shared core contracts with Python, JavaScript, web, and Godot parity validation.
- Semantic accessibility source contracts, focus continuity, reduced-motion support, and responsive layouts.
- Protected GitHub integration, exact-commit Pages validation, deterministic packaging, provenance, SPDX SBOM, and checksums.
