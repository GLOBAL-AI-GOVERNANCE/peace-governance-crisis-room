# Re-audit Triggers

Re-run the full source audit and affected higher gates when any of these changes:

- `Main.gd` decision, scoring, audit, export, or policy functions;
- governance policy, scoring rubric, scenario JSON, controlled language, or schema;
- evidence expected markings or recommended actions;
- Godot major/minor version or export settings;
- release workflow or dependency/action pin;
- public maturity, safety, or validation claims;
- twelve months elapse from the last determination.
