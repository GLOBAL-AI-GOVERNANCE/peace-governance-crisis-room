# What This Game Can and Cannot Teach

## What It Can Teach

This game can help reveal:

- How players make decisions under uncertainty.
- Where evidence review breaks down.
- How public pressure creates overclaiming risk.
- Whether controlled release language improves discipline.
- How civilian protection concerns alter public-release choices.
- How teams interpret confidence scoring.
- What training or doctrine gaps remain.

## What It Cannot Teach

This game cannot:

- Predict real-world state behavior.
- Prove a policy will work in a live crisis.
- Determine legal responsibility.
- Authenticate real media.
- Replace expert analysis.
- Replace official review.
- Model all operational, legal, diplomatic, or intelligence constraints.

## Correct Use

Use this game as a learning laboratory and decision-friction revealer. Do not overclaim outputs from a single playthrough.
