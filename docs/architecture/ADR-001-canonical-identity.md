# ADR-001: Canonical identity

**Status:** Accepted for the `v0.3.0-rc1` public review candidate.

## Decision

- **Product:** `Peace OS: Crisis Room`
- **Repository:** `GLOBAL-AI-GOVERNANCE/peace-os-crisis-room`
- **Descriptor:** Fictional, human-accountable crisis-governance simulation

Required clarification:

> Peace OS is the product name. This project is not a computer operating system.

## Rationale

The product sits inside the Global AI Governance organization, so repeating “Governance” in the product title is unnecessary. “Peace OS” names the governing doctrine and design language; “Crisis Room” names the bounded simulation experience.

The product name does not imply a general-purpose computer operating system, operational command platform, emergency-response system, intelligence system, or autonomous authority.

## Historical continuity

The public `v0.2.2` baseline used the title **Peace Governance Crisis Room**. That name remains in historical audit and release records only. Existing tags and releases must not be rewritten.

The live repository must be explicitly renamed by an authorized administrator before this candidate is published so GitHub reports the exact canonical identity above rather than only redirecting the former URL.
