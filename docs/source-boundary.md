# Source Boundary

This repository contains only the public-safe source needed to understand, review, validate, and run the fictional simulation.

Allowed in this repository:

- fictional scenarios;
- source code;
- validation scripts;
- schemas;
- release boundaries;
- facilitator and workshop guidance;
- public-safe doctrine and policy notes.

Not allowed in this repository:

- live incident data;
- personal data;
- classified, controlled, or confidential material;
- private outreach lists;
- raw chat archives;
- private research dossiers;
- campaign drafts;
- unsupported allegations about identifiable people or organizations;
- generated binaries or untested executable builds.

The repository may inherit general methods such as claim/evidence separation, uncertainty disclosure, human release authority, civilian protection, and de-escalation. It does not validate any external private archive or unrelated historical claim.
