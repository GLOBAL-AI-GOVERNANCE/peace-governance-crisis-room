# Workshop Guide

## Workshop Title

Peace OS: Crisis Room — Verification Before Amplification Under Crisis Pressure

## Learning Objectives

Participants should learn to:

- Review evidence before scoring confidence.
- Match public language to uncertainty.
- Protect civilians and sensitive witnesses before release.
- Recognize information-integrity and translation risks.
- Use decision gates to slow escalation.
- Interpret AAR outputs as learning signals, not predictions.

## Suggested Format

1. Pre-brief: explain the Peace OS doctrine.
2. Playthrough: run one or both scenarios, depending on workshop time.
3. Score review: inspect final meters and AAR.
4. Facilitated debrief: discuss decision friction.
5. Repeat: run second scenario or compare teams.

## Workshop Outputs

- Completed AAR report
- Debrief notes
- List of workflow gaps
- Candidate improvements for v0.3 or institutional pilot
