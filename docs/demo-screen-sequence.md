# 60-Second Demo Screen Sequence

This file provides a screenshot/GIF storyboard for GitHub README assets.

## Sequence

1. **Main Menu**  
   Show the title, policy boundary, facilitator toggle, and two scenarios.

2. **Scenario Briefing**  
   Show the scenario frame and crisis dashboard.

3. **Evidence Inbox**  
   Show evidence cards with unread/reviewed states.

4. **Evidence Detail**  
   Show one card being flagged, marked sensitive, marked for follow-up, and used in confidence assessment.

5. **Confidence Scoring**  
   Show the defensible confidence choice.

6. **Public Release Decision**  
   Show scenario-aware controlled language.

7. **Final Governance Actions**  
   Show clean checkmarks for selected actions.

8. **Score Summary**  
   Show final meter values and performance label.

9. **After-Action Review**  
   Show diagnostic sections: what went right, overclaims, misses, civilian protection, information integrity, recommended better decision.

10. **Facilitator / Observer View**  
    Show hidden confidence range, teaching notes, and debrief prompts.
