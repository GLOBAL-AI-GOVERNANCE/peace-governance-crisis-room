# Facilitator Guide

## Purpose

This guide helps a facilitator use Peace OS: Crisis Room in a classroom, workshop, tabletop, or policy-analysis setting.

## Recommended Session Length

- 10 minutes: introduction and boundary statement
- 20 minutes: individual or team playthrough
- 15 minutes: score review
- 20 minutes: after-action discussion

## Core Debrief Questions

1. What did the player treat as confirmed before it was verified?
2. Which evidence created the most pressure?
3. Did the player protect civilians before public release?
4. Did the release language match the confidence level?
5. Did public pressure distort decision quality?
6. What would need to change before this workflow could be used in a real institution?

## What To Observe

- Evidence skipped or reviewed too quickly
- Overclaiming in confidence scoring
- Release language stronger than evidence supports
- Civilian data exposure
- Failure to trigger information-integrity review
- Failure to separate humanitarian urgency from public attribution

## Boundary

Do not use live, classified, operational, or personally identifying data in workshops. Use only scripted scenarios or sanitized examples.
