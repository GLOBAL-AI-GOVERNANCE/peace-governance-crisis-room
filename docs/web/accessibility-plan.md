# Web Accessibility Plan

The semantic browser client is designed around native headings, landmarks, fieldsets, radios, checkboxes, buttons, a skip link, visible focus, a polite live region, responsive reflow, and reduced-motion support.

Source structure is not conformance. Before any accessibility claim, test with:

1. keyboard only;
2. a desktop screen reader;
3. 200% text zoom and 320 CSS-pixel reflow;
4. contrast and non-color information checks;
5. reduced-motion settings;
6. at least one user who relies on assistive technology.

Document defects, environment, browser, assistive technology, and retest results.
